# Tests

Fixtures under `fixtures/` are Rust-owned regression tests (the host TS that produced them is gone). Every `*_fixtures.rs` replay (decide, estimate-sizes, hw, probe, session, argv, hls, mp4, report) honours `BLESS=1`: a mismatching case gets its `expected` rewritten from the current Rust output (sorted keys, the file's own layout, nothing written when it already matches). Workflow: change the code, `BLESS=1 cargo test -p fliks-engine-core --test <suite>`, review `git diff fixtures/`. Never edit `expected` by hand. `remux_assembler` (binary expected files) is not blessable.
