# Tests

Fixtures under `fixtures/` are Rust-owned regression tests (the host TS that produced them is gone). Every `*_fixtures.rs` replay (decide, estimate-sizes, hw, probe, session, argv, hls, mp4, report) honours `BLESS=1`: a mismatching case gets its `expected` rewritten from the current Rust output (sorted keys, the file's own layout, nothing written when it already matches). Workflow: change the code, `BLESS=1 cargo test -p fliks-engine-core --test <suite>`, review `git diff fixtures/`. Never edit `expected` by hand. `remux_assembler` (binary expected files) is not blessable.

- `crates/core/src/api.rs` (unit): MediaInfo/DeviceProfile/SourceScan round-trip equal to the host JSON, unknown fields ignored.
- `crates/core/tests/decide_fixtures.rs`: every `fixtures/decide/*.json` input (`info`, `device`, `scan`) round-trips the wire types, and `decide(input, hostCaps, config)` equals `expected` (numbers compared as f64; mismatches print the fixture name and the differing JSON paths; explicit `SKIPPED` allowlist, empty). See `docs/spec/decide.md`.
- `crates/core/tests/estimate_fixtures.rs`: every `fixtures/estimate-sizes/*.json` (`input` = `{info, fileSize}`, `expected` = the host controller's `downloadQualities` result) through `estimate_sizes()`. See `docs/spec/estimate-sizes.md`.
- `crates/engine/tests/control_plane.rs`: bearer auth, hello, config revision rule, `POST /v1/decide` (400 before the first config, then the golden `android-tv-h264-sdr-mkv-cpu-720p` decision with a detected CPU-only host).
- `crates/engine/tests/control_plane.rs` also covers `POST /v1/estimate-sizes` (bearer, 1080p entry).
- `crates/core/tests/hw_fixtures.rs`: every `fixtures/hw/*.json` (`env` = `/dev/dri` + sysfs, `calls` = what each ffmpeg argv answered with exit code, stderr and the `-encoders` listing, `pause.samples`) through `core::hw::detect()` with a replay runner; `HostCaps`, `Capabilities` and the set of (argv, timeout) pairs run must equal the TS's `expected`; an argv with no recorded answer fails the test. Scenarios: `host-ffmpeg-no-driver`, `jellyfin-raptor-lake`, `jellyfin-arc-pinned` (recorded on this machine: Raptor Lake iGPU + Arc A370M, host ffmpeg 8.0.1 and the engine image's jellyfin-ffmpeg 8.1.2 with `--device /dev/dri`), and synthetic ones scripted by the harness: `linux-cpu-only`, `linux-vaapi-amd`, `linux-qsv-intel-ihd`, `linux-qsv-partial` (blacklisted ids), `linux-qsv-broken-vaapi-fallback`, `linux-gpu-broken-cpu-fallback`, `linux-nvenc`, `win32-amf`, `win32-qsv`, `darwin-videotoolbox`. nvenc, amf/win32 and videotoolbox/darwin are not real hosts: the argv come from the TS, the answers are scripted. Re-record a real scenario by hand on a machine that has it; see `docs/spec/hw.md`.
- `crates/core/src/hw` (unit): `libfdk_aac` word boundary, iHD log match, pause verdict steps, the probe encoder table lists the same ids as the decision's registry.
- `crates/engine/tests/hw.rs`: 503 + `Retry-After` on `/v1/capabilities` and `/v1/decide` until detection ends, then the detected caps; a `gpuRenderNode` change re-detects on the new node and coalesces pins made during a run. `crates/engine/src/hw/io.rs` (unit): render-node enumeration over a fake sysfs, a missing ffmpeg fails closed.
- `crates/engine/tests/supervise.rs` (unix): failing host is restarted with the injected env.
- `crates/engine/tests/supervise.rs` also covers `--supervise --upstream`: the host gets `PORT` from the upstream URL and the public listener address is printed.
- `crates/engine/tests/gateway.rs`: the gateway against stub upstreams (axum, raw tokio-tungstenite): method/path/query/body/header forwarding with `X-Forwarded-*` and hop-by-hop stripping (including headers named by `Connection`), 1 GiB download and upload streamed with backpressure (a stalled peer must leave the producer under 512 chunks ahead), SSE event one seen before event two exists, WebSocket echo through the upgrade splice, `502` for a dead upstream while an engine route still answers, engine vs forwarded matching (direct play, playlists, segments, subtitles, sprites vs `edl`, `info/*`, non-GET, unknown paths) and `/v1/*` forwarded rather than served on the public listener. `crates/engine/src/gateway.rs` (unit): the Fliks table against the route inventory, bad tables and upstream URLs rejected.
- CI drift: `openapi.json` matches the types; `oasdiff breaking` against main.
- `crates/engine/tests/openapi_wire.rs`: every component of the generated OpenAPI document gets a sample built from its schema (one per `oneOf` alternative, so every enum variant), read as its Rust type and written back; every key written must be a property of the schema, and a component without a check fails the test (the drift that left `EngineEvent`/`AudioPlan` fields snake_case).
- `crates/core/tests/probe_fixtures.rs`: every `fixtures/probe/*.json` (not `_*`) replays the recorded output of ffprobe, mkvmerge and ffmpeg through `probe()` with a `Tools` stand-in; the result must equal the host's `{ ok, info }` (comparison in `tests/common`; `expected.nulls` are paths the host writes as `null`, absent here), every run must use the recorded arguments, no recorded run may be left unmade, and a streamed run must end where the host ended it. Also replays each tag-reading fixture with `mkvTags: false`. Fixtures: 35 corpus files recorded with the real tools (`file`, `moviehash`) and 90 hand-written cases (Dolby Vision, HDR10+, rotation, frame-rate lies, late audio, odd tags, crop retries, failures); corpus re-recording: `PROBE_TOOLS=$(tools/probe-tools.sh) tools/gen-probe-corpus.sh`.
- `crates/core/src/probe/tests.rs` (unit): `fixtures/probe/_titles.json` (language and forced/SDH inference of 1 142 titles), `_fps.json` (`toFixed(3)` frame-rate text of 489 doubles), `_moviehash.json` (the host's hash of sparse files up to 10 GiB next to the specified one) against the engine; `probe::{js,lang,mkv,crop}` unit tests.
- `crates/engine/tests/probe_live.rs`: `corpus_matches_the_host` (no-op unless `PROBE_CORPUS_DIR`; set `FFPROBE_PATH`, `FFMPEG_PATH`, `MKVMERGE_PATH` to the tools of `tools/probe-tools.sh`) runs the real `POST /v1/probe` on the 35 corpus files and compares `ok`, `info` (without `schemaVersion`, which the engine stamps) and `moviehash` to the fixtures; `probe_validates_the_request` (relative path 400, unreadable file `ok: false`).
- `crates/engine/src/probe/run.rs` (unit, unix): output, exit status, missing binary, timeout, output cap and early stop of the process runner with shell-script tools.
- `crates/core/src/session` (unit): variant suffix round trip and `base_profile_hash` edge cases, `SegmentSet` queries and names, segment responses (503/404/410), resume matrix rows and the remux wait window, throttle hysteresis, run lead, playhead, eligibility, pause by capability, lifetimes (expiry, revive, cap, job idle), cache TTL/LRU, cache layout, `cache/v1` profile hash (canonical-string and hash snapshots: changing them orphans every cached title, raise `CACHE_NAMESPACE` instead; every input forks the hash; a var_stream_map group ignores the picked track).
- `crates/core/tests/session_fixtures.rs`: every `fixtures/session/*.json` through `core::session`, the result must equal what the host's real services returned (`session_common::run` maps each `kind` to the engine function: `keys`, `resolve-existing`, `throttle-decide`, `run-lead`, `job-playhead`, `throttle-eligible`, `throttle-tick`, `cache-gc`, `job-idle`, `live-gc`, `live-cap`, `sid-gate`). A file is one vector or a `matrix-*` of cases (one per line). Vectors: the 12 `resolve-existing-session.spec` cases, the 18 `ffmpeg-throttle.service.spec` cases (one vector per assertion), the TTL/LRU cases of `transcode-cache.service.spec` and `streaming-lifecycle.spec`, plus synthetic matrices: seek and quality switch (positions x run states x cache shapes x quality match, transcode and remux with frontiers and throughput), throttle decisions and ticks (capability x switch x variant x viewers x span), TTL/LRU, live-session expiry/cap, job idle times, keys. Not vectors: the 503/404 segment rule (inline in the host controller), the tick re-entrancy guard (JS).
- `crates/core/tests/argv_fixtures.rs`: every `fixtures/argv/*.json` (`kind` vod/remux/encoder/live/iframe, `hostCaps`, `env` = render node + `FLIKS_OPENCL_DEVICE`, `input` = the TS option bag) through `core::args`; the argv must equal `expected.argv` element by element, or the error `expected.error` (first differing element printed). Recorded from the host specs `ffmpeg-args.golden`, `codec/encoders/{amf,nvenc,hevc-videotoolbox}`, `live-ffmpeg-args`, `iframe-trick-play`, `programme-video-map`, `output-timeline`, `ts-timeline-offset`, `subtitle-overlay-filter`, plus a matrix built from `fixtures/decide` (Transcode as two VOD runs on its own and a rotating other backend, DirectStream as remux runs) and a live matrix.
- `crates/core/src/args` (unit): JS number text (`String(x)`, `toFixed` ties, `formatSeconds`, `parseBitrateToBps`); the file output (MP4/MKV) starts with the same layer-1 argv as the HLS run of the same request, maps the picked or every track, `-an` without audio.
- `crates/core/tests/hls_fixtures.rs`: every `fixtures/hls/*.json` (`fn`, `args`, `expected.ok`; one host call each) through `core::hls`, byte-identical text: the master (`generateMasterPlaylist`), `buildVodPlaylist`/`buildVariableVodPlaylist`/`buildIFramePlaylist`, the variant/audio/I-frame/subtitle routes of the real controller (collaborators stubbed), `remuxBandwidthBps`, `pinnedRungName`, `copySourceCodecString`. Sources: calls recorded while replaying `master-playlist.golden.spec` (9), `master-playlist.spec`, `streaming.controller.spec`, plus a synthetic matrix (sizes x SDR/HDR variants x remux, audio layouts, pins, no-ABR, subtitles, frame rates, I-frame, durations x segment lengths, route sessions).
- `crates/core/tests/mp4_fixtures.rs`: every `fixtures/mp4/*.json` (bytes base64, ticks as strings; `expected` is `{ ok }` or `{ error, code? }`: a `code` means a Node buffer bounds error, matched by `Mp4Error::OutOfRange`, else the message must be equal) through `core::mp4`. Sources: calls recorded while replaying `timeline`, `cmaf-rewrite`, `remux-assembler`, `segment-boundaries`, `source-timeline`, `output-timeline` (its `remuxRunStart` calls) and `streaming.controller` specs (at most 3 per test and 20 per spec and function), a synthetic matrix (inits v0/v1, edits, empty edits, trex, tfdt v0/v1 and overflow, CMAF shapes, keyframe grids incl. open GOP, negative origin, breaks; run starts with and without encoded audio), and `real-*`: one 2 s ffmpeg HLS-fMP4 clip and one per-frame-fragmented AAC track.
- `crates/engine/tests/remux_assembler.rs`: `fixtures/mp4/assembler/*.json` (inline and multi-audio, keyframe and uniform grids, seeks, an encoded AAC rendition): real jellyfin-ffmpeg 8.1.2 remux runs (GOP files and growing `a<i>.mp4`, the plan) and the served files the host's `RemuxSegmentAssembler` built from them after a clean exit; `engine::remux::Assembler` must write the same files byte for byte and end on the same frontiers. - `crates/engine/src/{cache,runtime,serve}.rs` (unit): `cache/v1` layout, index walk and the one-shot purge of the old layout; `purge_from` keeps segments before a restart; byte ranges (`S-E`, `S-`, `-N`, 416 cases), `X-TIMESTAMP-MAP`, `encodeURIComponent` token suffix, credential order, content types. `crates/core/src/session/plan.rs` (unit): rung profiles, valid qualities, top rung, `secondsToSegmentIndex`, `playPath`, audio encoder ids.

- `crates/engine/tests/runtime_watchdog.rs` (unix, always, fake ffmpeg shell scripts that ignore SIGTERM and write nothing; checked with `Engine::ffmpeg_pids`): main, early and remux runs of one session are all gone after each session end (DELETE, `stop` command, expiry + GC tick, revoke, invalidate, owner-cap eviction, engine shutdown); a run whose session ended before it registered is stopped by the next GC tick; a silent run is SIGKILLed after `jobStallTimeoutMs`, ends `Failed` with `JobEnded.reason = stalled`, restarts on the next request and dies with its session; a run that writes stderr lines, or is paused, is not stalled; an early companion that keeps talking but outlives its `-to` media time + the timeout is killed (`overran`).
- `crates/core/src/session/lifetime.rs` (unit): `job_watch` (stall boundary, progress resets it, paused and disabled exempt, early overrun boundary) and the `jobStallTimeoutMs` default (30 s when absent, 0 kept).
- `crates/engine/tests/runtime_e2e.rs` (real ffmpeg; `#[ignore]` unless built with `ENGINE_E2E` set): `PROBE_TOOLS=$(tools/probe-tools.sh); FFMPEG_PATH=$PROBE_TOOLS/ffmpeg FFPROBE_PATH=$PROBE_TOOLS/ffprobe ENGINE_E2E=1 cargo test -p fliks-engine --test runtime_e2e`.
